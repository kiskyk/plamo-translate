Getting started with the cache layer

When the cache is cold, the first request has to read every layer from disk, so expect the initial response to take several seconds. Subsequent requests reuse the weights that are already resident in memory.

Install the package with npm install fastcache, then call the setup function before your server starts listening.

const cache = createCache({ size: "2GB" });
cache.warm();
  • Entries expire after one hour unless you pin them.
  • Pinned entries survive restarts, but they count against your quota.
OptionMeaning
sizeMaximum memory the cache may use.
ttlHow long an entry lives before it is evicted.

Troubleshooting

If you run out of memory, the runtime will silently move some layers to the CPU, which keeps things working but can make generation five to ten times slower.
